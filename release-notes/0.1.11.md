# iFaceMatch 0.1.11

Customer Hosted — Console login CSRF hotfix.

## Changes

- Preserve the login CSRF nonce across repeated GET requests to the login page.
- Return HTTP 204 for favicon requests, preventing unwanted login redirects and nonce rotation.
- Regression tests for repeated login and the commercial setup routes.
- **Server, Secure Core, Model Pack and Web SDK are unchanged** from the signed 0.1.10 baseline.

## First pilot upgrade

On the pilot host `srv855672`, download the `ifacematch-update.sh` asset through GitHub HTTPS. Review it, then run `bash ifacematch-update.sh --check` to download and verify the package without restarting services. After approval and a recoverable backup, run `bash ifacematch-update.sh 0.1.11` as root. This updater is pinned to the first pilot host and is not a general-purpose installer.

Published downloads are public. A valid commercial license remains mandatory for use.
